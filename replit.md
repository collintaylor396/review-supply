# Project

This imported repository is a single static HTML page. Opening `index.html` redirects the browser to `https://www.google.com` and appends the page's URL fragment to the Google URL.

## Preview on Replit

Run the **Start application** workflow, which serves the repository root on port 5000 with Python's built-in HTTP server. No packages or secrets are required.

## Publish

The project is configured for Static Deployment with the repository root (`.`) as its public directory. Publish through Replit's Publishing interface; no build step is needed.
